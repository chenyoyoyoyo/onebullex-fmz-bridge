# 一分鐘鱷魚與碎形突破：Spartans 範例

這是Pine v5交易邏輯移植到FMZ JavaScript的完整範例。預設 **PAPER、不下單**。用於理解與驗證串接，不是獲利推薦或所有Pine的通用轉譯器。

## 使用檔案

- `Alligator-Fractal-original.pine`：保留可執行Pine邏輯及MPL標示。
- `Alligator-Fractal-OneBullEx.js`：將此**完整單檔**貼到FMZ JavaScript策略編輯器；不要貼到SSH終端機。
- `parameters.json`：FMZ的8個策略參數。
- `engine.js` / `runtime.js` / `execution.js`：指標、運行狀態與成交執行模組。
- `build.js`：離線重新產生單檔；`*.test.js`：離線測試，沒有網路或真實下單。

先展示移植差異並另存新策略，不覆寫原策略。FMZ交易所設定可命名 `OneBullEx-Spartans`；若使用其他名稱，將 `AF_ACCOUNT_LABEL` 改成完全相同的名稱。程式只允許一個交易所物件與BTC_USDT，公開範例不會自動選帳戶。

## FMZ參數

| 名稱 | 類型 | 預設 | 意義 |
| --- | --- | --- | --- |
| AF_RUN_MODE | 數字 | 0 | 0=PAPER，1=真實送單；交易環境另由bridge決定 |
| AF_SIZE_MODE | 數字 | 1 | 0=原權益百分比算法，1=固定張數驗證 |
| AF_FIXED_CONTRACTS | 數字 | 1 | 固定張數；不是BTC幣數 |
| AF_EQUITY_PCT | 數字 | 10 | 下單名目金額占合約權益比例，百分數 |
| AF_APPROVED_CAP | 數字 | 1 | 本帳戶已核准且與伺服器一致的單筆上限 |
| AF_MAX_ROUND_TRIPS | 數字 | 1 | 完成幾個開平倉回合後停止；0=持續 |
| AF_SHOW_LINES | 布林 | true | 顯示均線與已確認碎形 |
| AF_ACCOUNT_LABEL | 字串 | OneBullEx-Spartans | 預期FMZ交易所設定名稱，精確比對 |

建立FMZ執行個體時選自己的專用託管者、K線1分鐘，加入正確交易所/BTC_USDT後確認紅色標籤。先跑PAPER並等待自然訊號；不能保證立即觸發。切換LIVE前先停止、取得環境/張數確認、更新參數並讀回；正式啟動由本人操作。

## 與Pine的對應及差異

- hl2的SMMA長度13/8/5，以SMA初始化，平移8/5/3根。牙齒(teeth)是均線交易條件，jaw/lips不額外作過濾。
- 5根嚴格高低碎形，右側2根收盤後才確認。交叉使用本根與上一根各自的碎形或牙齒數值。
- 新收盤1分鐘K線後計算；啟動用至少100根已收盤歷史初始化，不補下歷史訊號。不同資料起點或來源可能影響指標與訊號。
- 同向不加碼。相反訊號先確認平倉再開新方向；預設只跑一回合，平倉後停止，不再開反向倉。
- 原Pine的權益10%是**名目曝險**。固定1張是明確的驗證覆寫；正常模式需切AF_SIZE_MODE=0。低於1張跳過，超過核准上限阻擋，不進位、不暗中縮單或拆單。
- 市價成交使用查單確認的AvgPrice，不假裝在訊號收盤價成交。入場訊號超過20秒不追；出場仍以減倉為目的。
- 圖表在確認時刻顯示可用碎形水平，不把交易訊號回畫到2根前。
- 牙齒交叉出場依賴主機持續運作，不是交易所原生止損，也沒有固定USDT最大損失承諾。
- 盈虧顯示使用單邊0.06%估算費用；交易所實際費率、資金費及帳本需另行對帳。

## 狀態與故障

PAPER使用真實行情但獨立模擬帳本；LIVE使用實際持倉。兩者_G狀態鍵分開。程式在送單前保存策略意圖及訂單journal，送單結果不明時不重送；遇外來倉位/掛單、持倉監看中斷超過60秒或缺K線，會停止待人工核對。

普通唯讀輪詢最多重試3次，成交確認異常仍採保守停止。停止不等於平倉。不要直接刪journal、複製執行個體或改名稱來繞過未對帳狀態。重啟已完成的一回合不會自動再下單；如需新回合，先對帳，再明確建立新的測試計畫。
